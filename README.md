# سوبر ماركت أبو عمار

واجهة متجر عربية RTL مبنية بـ React وVite وTailwind CSS. المنتجات والأسعار والمخزون في المشروع بيانات عرض توضيحية وليست بيانات المتجر الفعلية.

## التشغيل

```bash
npm install
npm run db:setup
npm run db:seed
npm run dev
```

يعمل خادم التطوير على المنفذ `5000`، ويُبنى الإنتاج باستخدام `npm run build`.

## إعداد واتساب

انسخ `.env.example` إلى `.env` وأضف رقم واتساب المتجر الحقيقي في `VITE_STORE_WHATSAPP`، بصيغة دولية من أرقام فقط، من دون `+` أو مسافات. لا تضع بيانات اعتماد أو رموز API في متغيرات `VITE_*`.

روابط واتساب تفتح رسالة جاهزة فقط. يجب على الشخص مراجعتها والضغط على «إرسال» داخل واتساب.

## حسابات المتجر والإدارة

- التسجيل والدخول عبر Clerk بالبريد الإلكتروني، مع صفحات عربية.
- العميل المسجل يستطيع حفظ بياناته ومراجعة طلباته.
- لا يوجد تسجيل أدمن مفتوح. حدّد بريد أول مسؤول في `INITIAL_ADMIN_EMAIL`، ثم أنشئ الحساب بهذا البريد وأكّد عنوانه. بعد ذلك يستطيع المسؤول دعوة بقية فريق الإدارة من لوحة المتجر.
- الدعوات لا ترسل بريدًا تلقائيًا: شارك رابط `/sign-up` يدويًا مع المدعو، ويجب أن يسجّل بالبريد المدعو نفسه.
- لا تضع بريدًا مشتركًا أو كلمة مرور افتراضية لحساب الإدارة.
- عيّن معرّف مساحة App Storage في `APP_STORAGE_BUCKET_ID`؛ يمكن نسخه من Settings للمساحة داخل App Storage في محرر Replit.

## ما يعمل

- تصفح الأقسام والأنواع والبحث والترتيب.
- تفاصيل المنتجات ومعرض الصور والفيديو، واختيار أحجام أو أنواع مختلفة بأسعار ومخزون مستقلين.
- المفضلة وسلة محفوظة في المتصفح.
- إنشاء الطلبات بعد تسجيل الدخول، وحفظها في قاعدة البيانات ليراها العميل وفريق الإدارة.
- لوحة إدارة محمية لإضافة الأقسام والمنتجات، تعديلها وحذفها، إدارة الخصومات والعروض، رفع الوسائط، متابعة الطلبات، وإدارة المسؤولين.
- قسم عروض يومية يعرض المنتجات ذات الخصم المفعّل من لوحة الإدارة.
- مساعد محلي يبحث في قائمة المنتجات التوضيحية؛ ليس نموذج ذكاء اصطناعي ولا يتصل بالمخزون الحي.
- بعد حفظ الطلب يمكن للعميل فتح مسودة واتساب ومراجعتها وإرسالها بنفسه. ملاحظات العميل والعنوان وتفاصيل الطلب تظهر للمسؤولين داخل لوحة الإدارة.

## ما يحتاج خدمة خلفية قبل الاستخدام التجاري

- استبدال منتجات وأسعار ومخزون العرض التجريبي ببيانات المتجر المعتمدة وإزالة علامة «تجريبي» بعد مراجعتها.
- تحديد رسوم التوصيل ومناطق الخدمة وسياسات الطلب مع المتجر.
- إشعارات واتساب تلقائية أو بريدية للطلبات؛ المتاح حاليًا عرض الطلبات داخل لوحة الإدارة ومسودة واتساب يرسلها العميل يدويًا.
- نموذج ذكاء اصطناعي خارجي. لم تتم إضافة مفتاح xAI؛ المساعد الحالي بحث محلي فقط.

لا تُفعّل الطلبات على منتجات تحمل علامة «تجريبي»؛ الخادم يرفض تسجيلها حتى لا تُستخدم أسعار أو مخزونات غير مؤكدة.
